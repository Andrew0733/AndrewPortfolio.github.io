About Project

Supplements, simplified.

Big Muscle is a dynamic online store for sports supplements in Egypt. Customers can browse products, apply offers, and place cash-on-delivery orders without creating an account.

The bilingual storefront switches between Arabic and English with right-to-left and left-to-right layouts. Behind it, a dedicated dashboard lets the store owner manage the shop without editing code.

Design Philosophy

High-energy design. Low-friction shopping.

The black foundation and strong red accents create an athletic, high-contrast identity while keeping attention on the products and key actions. A responsive mobile-first layout, clear pricing, and instant language switching make the experience easy to use across devices and languages.

UX / Conversion Strategy

Fewer steps.
More confidence.

The shopping experience is designed to reduce friction: no forced registration, visible order totals, region-based delivery fees, and a checkout form that keeps the essential details together.

Technical Build

From storefront to back office.

A vanilla JavaScript storefront connects to a REST API and cloud-backed services for product data, images, and deployment.

Responsive storefront built with vanilla JavaScript and modular scripts.
